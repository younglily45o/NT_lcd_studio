# LCD Studio 通用设备支持

用户要求 `~/Desktop/Tools/lcd_studio` 通用，取消只适用 V9 的限制。本次只修改电脑工具仓库，不修改或编译任何具体机型SDK。

## 实现选择

采用现有LCD Studio协议2作为公共接口；相比扩展机型枚举，此方式让新机型无需再改电脑端。相比任意串口文本协议可配置，此方案保留现有完整参数校验及回读确认，不引入未定义的寄存器写入规则。这里的协议边界、标识长度和默认方案是实现者基于当前代码作出的选择。

- `hello <model> 2` 的 model 为1~32字节ASCII标识，只含字母、数字、下划线、连字符、点。合法标识均可连接；包括P618_V9、DC162、未来机型。机型只用于显示和方案来源，不再决定是否开放连接。
- 协议2仍代表RGB三路33点Gamma和五项颜色控制，CRC固定105字节。协议1、未知版本、损坏/额外字段仍拒绝；不伪造不受支持的颜色控制。
- USB VID/PID只展示，不作机型白名单或固定设备优先规则。115200/8N1及DTR/RTS维持现有传输约定。
- 任意机型均须完整读回且用户接受载入后才可下发。连接不覆盖当前项目，取消不解锁；错误暂停自动模式，重新连接必须重新接受读取。
- 默认项目使用线性Gamma和中性颜色；DC162保留为手动选择的参考预设。旧JSON/C格式和已有文件保持兼容，设备导入名称与来源使用实际机型。
- 标题、帮助、错误和通用协议说明去除V9专用升级要求。V9的USBCDC标记及历史固件版本只能作为该机型的接入示例。
- 仓库提供可配置设备标识的便携C协议核心与SDK接入说明。硬件read/apply及USB收发由各SDK适配；文档明确完整包/对齐缓冲、超时和真实硬件回读。通用不代表任意未适配固件可直接使用。
- 发布0.6.0 Windows包并附便携C核心/说明。验证多机型握手、完整读写、错误拒绝、读取确认、默认项目，以及独立C核心到Rust的伪终端联调；不声称真实硬件验证。
